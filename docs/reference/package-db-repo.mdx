# db-repo package

`pkg/db-repo` provides a model-oriented SQL repository interface with create, read, update, delete, and query operations. It also contains the model-event publisher notifier used to send repository notifications.

## API and activation

Repository-operation timing is an explicit opt-in: wrap a repository with `db_repo.NewMetricRepository(config, logger, repo)`. The wrapper records `Create`, `Read`, `Update`, `Delete`, and `Query`; it does not override `Count`, and the package does not automatically wrap every repository. Model-event notification counts are emitted by the separate `db_repo.NewPublisherNotifier` path after each publisher result. See [`NewMetricRepository`](https://github.com/justtrackio/gosoline/blob/dd90ce372ff3/pkg/db-repo/metric_repo.go#L27-L36) and [`NewPublisherNotifier`](https://github.com/justtrackio/gosoline/blob/dd90ce372ff3/pkg/db-repo/notification_publisher.go#L19-L22).

## Metrics

The table lists names and units authored by Gosoline. The OpenTelemetry writer exports names with a `gosoline.` prefix and converts authored `ms` durations to the OpenTelemetry duration unit. See the [metric schema reference](/reference/metric-schema) for the writer contract and `{{default}}` dimension behavior.

| Metric | Instrument | Authored unit | Dimensions | Description |
|--------|------------|---------------|------------|-------------|
| `db.repo.operation.duration` | Histogram | `ms` | `operation.name`: `create`, `read`, `update`, `delete`, `query`; `model.id`: repository model ID; `error.type`: `{{default}}` on success, `operation_failed` on error | Records one observation after each wrapped repository operation. The observation count is the operation count; failures remain observations and are identified by `error.type`. `Count` is not wrapped by this metric repository. |
| `db.repo.model_event.notifications` | Counter | `count` | `model.id`: configured model ID; `error.type`: `{{default}}` when publish succeeds, `notify_failed` when it returns an error, including cancellation | Adds one after each model-event `Publisher.Publish` result. Notification type is not a dimension; the counter records publish outcomes rather than the underlying database operation. |
