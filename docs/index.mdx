Gosoline is a Golang-based application framework specialized for building microservices in the cloud. It provides tools for handling most of the common challenges like configuration, logging, structured code execution, handling http requests, asynchronous message processing, writing integration tests and much more.

## Primary use cases

There are three primary uses cases for gosoline:

<CardGroup cols={3}>
  <Card title="HTTP Server" href="/how-to/http-server">
    Build REST web services with HTTP handling, caching, OAuth, and more.
  </Card>
  <Card title="Message Queues" href="/getting-started/create-a-consumer">
    Process asynchronous messages from Kafka, Redis, or other streaming systems.
  </Card>
  <Card title="Kernel Module" href="/getting-started/create-an-application">
    Build a module using Gosoline logging, configuration, and application lifecycle tools.
  </Card>
</CardGroup>
