📄️Naming patterns

Gosoline uses naming patterns to generate consistent names for resources (SQS queues, SNS topics, DynamoDB tables, Kafka topics, Redis keys, metric namespaces, tracing service names, ...).

📄️Package blob

pkg/blob provides batched object-storage access through named stores and a worker-backed BatchRunner. The runner uses the configured S3 client and processes each object in a batch through separate read, write, copy, and delete workers.

📄️Package cfg

With the cfg package, you can configure and use configurations in your gosoline project.

📄️Package cloud/aws

The cloud/aws package

📄️Kinesis shard reader

ShardReader is the per-shard worker in github.com/justtrackio/gosoline/pkg/cloud/aws/kinesis. It polls a Kinesis shard with GetRecords, passes record payloads to a RecordHandler, and advances the shard checkpoint. It runs until the shard is finished or its context is canceled.

📄️Kinesis RecordWriter

RecordWriter in github.com/justtrackio/gosoline/pkg/cloud/aws/kinesis writes records to one configured Kinesis stream using PutRecords. Construct it with NewRecordWriter(ctx, config, logger, settings) and a *RecordWriterSettings; use PutRecord for one record or PutRecords for a batch. The writer resolves the full stream name and Kinesis client from configuration, splits requests at the Kinesis batch limit, and retries records rejected in a response.

📄️Concurrency scheduler

The pkg/conc/scheduler package groups keyed jobs into batches and sends each batch to a caller-provided runner. Each ScheduleJob call receives the result associated with its key.

📄️Package db-repo

pkg/db-repo provides a model-oriented SQL repository interface with create, read, update, delete, and query operations. It also contains the model-event publisher notifier used to send repository notifications.

📄️Package db

pkg/db creates managed SQL connections as *sqlx.DB values from named database settings. It installs a driver wrapper for connection-attempt metrics and reads live pool state from database/sql statistics.

📄️Package dbx

The dbx package provides a fluent API to build SQL queries.

📄️Package ddb

pkg/ddb provides a DynamoDB repository interface for model persistence. Gosoline's mdlsub.NewOutputDdb wraps its repository with ddb.NewMetricRepository; the wrapper instruments PutItem, while delete operations use DeleteItem and do not pass through this metric hook.

📄️Package fixtures

While using gosoline you are able to define fixtures directly in code.

📄️Gosoline SDK HTTP server package

The Gosoline SDK's pkg/httpserver package integrates an HTTP server with the application kernel. Import it as github.com/justtrackio/gosoline/pkg/httpserver; httpserver.New(name, definer) returns a kernel module factory and reads server configuration from httpserver.. The SDK installs its request-metric middleware and server metric recorder as part of constructing the server.

📄️Package grpcserver

The Gosoline SDK's pkg/grpcserver package (import path github.com/justtrackio/gosoline/pkg/grpcserver) wraps a gRPC server as a kernel module. grpcserver.New(name, definer, middlewares...) returns a module factory, reads server settings from grpc_server., and registers the defined services. Register the factory with the application using application.WithModuleFactory.

📄️Package http

The Gosoline SDK's pkg/http package (import path github.com/justtrackio/gosoline/pkg/http) provides a configured, reusable client for outbound HTTP requests. Its Client interface builds requests through NewRequest() and exposes Get, Post, Put, Patch, and Delete operations.

📄️Package httpserver

Package httpserver provides a modular HTTP server built on Gin and the gosoline kernel. It offers structured request binding, typed responses, middleware, SSE streaming, and dependency-injected handler registration.

📄️Package kafka consumer metrics

The pkg/kafka/consumer component polls Kafka records, coordinates callback processing, and commits offsets. A stream input configured with type: kafka uses this consumer path; the public consumer.NewConsumer constructor also creates a consumer directly. These measurements describe the Kafka client processing cycle, not an application's business outcomes.

📄️Package kafka producer metrics

The pkg/kafka/producer component sends records synchronously and reports per-call results. A stream output configured with type: kafka uses this producer path; the public producer.NewProducer constructor also creates one directly. These metrics describe producer-call outcomes and timing, distinct from Kafka broker and wire-batch hook measurements.

📄️Package kafka client hooks

The pkg/kafka package's MetricsHook records broker connection and throttle events plus franz-go produce/fetch wire batches. These are transport-level hook measurements; the Kafka consumer and producer packages emit separate client-operation metrics.

📄️Kinsumer

Kinsumer is the current exported Kinesis consumer API in github.com/justtrackio/gosoline/pkg/cloud/aws/kinesis. It coordinates shard ownership and checkpointing across clients, runs per-shard readers, and delivers record payloads to a RecordHandler. Construct it with NewKinsumer(ctx, config, logger, settings) and a *Settings (Settings.StreamName is required), then call Run(ctx, handler) to consume. The Kinsumer interface also exposes Stop and IsHealthy for lifecycle management.

📄️Package kvstore

pkg/kvstore provides generic model-keyed stores with in-memory, Redis, and DynamoDB backends. Its interface supports individual and batch reads, writes, and deletes.

📄️Rate limiter

The pkg/limit package provides rate limiters for operations that must wait until a limit permits them to proceed. The common Limiter interface exposes Wait(ctx, prefix) error; a fixed-window limiter can delay a caller after capacity is reached.

📄️Package log

The gosoline logger is based upon a simple interface that uses handlers internally to enable fully customizable log handling.

📄️Model subscription callback

The pkg/mdlsub package adapts model subscription messages to the stream consumer callback interface. It reads model and version details from message attributes, selects a transformer from the supplied model core, and persists transformed output.

📄️Package metric

The Gosoline metric package provides the framework metric writer pipeline and an optional Prometheus scrape endpoint. It also supplies a logger handler that records warn- and error-level log records as a framework metric. The Metric schema reference remains the source of truth for canonical Gosoline metric names, units, dimensions, writer transformations, and migration history; this page covers package activation and endpoint-specific exports.

📄️Package stream Redis list input

The stream package's Redis list input implements the stream Input interface. It blocks on a configured Redis list with BLPOP, decodes each payload as a stream.Message, and passes decoded messages into the consumer pipeline.

📄️Package stream Redis list output

The stream package's Redis list output implements the stream Output interface. It encodes the supplied writable messages into Redis list entries and appends them with RPUSH to the configured list. Use it when a producer should publish stream messages to a Redis list.

📄️Package test

This package acts as a wrapper over Golang's testing module.
